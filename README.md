# 🏎️ Análisis Exploratorio de Datos: Fórmula 1

Este repositorio contiene un pipeline interactivo de limpieza y análisis exploratorio inicial construido en Python. El proyecto procesa datos históricos del Campeonato Mundial de Fórmula 1 para extraer métricas clave de rendimiento de escuderías y pilotos mediante el uso de Pandas.

## 📁 Origen de los Datos
El conjunto de datos utilizado corresponde al histórico del **Campeonato Mundial de Fórmula 1 (1950-2020)**, extraído de Kaggle. El script está diseñado para procesar el archivo `results.csv`, el cual detalla el rendimiento individual de los pilotos en cada carrera histórica. 

*Nota: Al pesar menos de 50MB, el archivo original puede incluirse directamente en este repositorio (recuerda subir el archivo `results.csv` junto a los scripts).*

## 🛠️ Instrucciones de Ejecución
